# Caisse de démonstration — Les Projets de Shaya

Site **de démonstration** de la caisse du stand, sur une adresse d'essai indépendante de la caisse réelle :
ventes fictives seulement, stockage séparé de celui de la caisse réelle, aucun accès à Firebase (écran du
stand, roue, tiroir). Ne pas utiliser pour de vraies ventes ni avec le terminal SumUp.

Construit par `outils/construire-site-demo.cjs` depuis la caisse (commit `15dae56c2a2611f6b97e1c4eb48119f805b18f11`).
